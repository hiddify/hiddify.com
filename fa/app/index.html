    راهنمای اپ هیدیفای

    یک لمس، تا اینترنت آزاد.

    اپ هیدیفای رایگان و متن‌باز است و روی Android، iOS، Windows، macOS و Linux با همان سادگی کار می‌کند. هر آنچه برای وصل ماندن لازم دارید، اینجاست.

    در این صفحه همهٔ آموزش‌های اپ را می‌بینید: اول «نصب» و بعد «استفاده» را بخوانید. فهرست کامل امکانات اپ در صفحهٔ README اپ در GitHub آمده است.

    نصب اپاندروید، iOS، ویندوز، مک و لینوکس کار با اپافزودن پروفایل و اتصال اینترنت آزاد رایگانوارپ رایگان در خود اپ هستهٔ هیدیفایموتور اپ در خط فرمان
