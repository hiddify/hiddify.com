## 1. جمع‌آوری داده‌ها { #data-collection }

### داده‌های VPN { #vpn-data }

- ما **هیچ** داده‌ای از VPN شما را جمع‌آوری یا ذخیره **نمی‌کنیم**.
- ما محتوای داده‌های VPN شما را تغییر **نمی‌دهیم**.
- ما **هیچ** داده‌ٔ حساس یا مخصوص کاربر را با طرف سوم به اشتراک **نمی‌گذاریم**.

این برنامه فقط یک برنامهٔ کلاینت است که کاربران با آن به سرورهای خودشان وصل می‌شوند. یعنی برنامه هیچ داده‌ای از VPN را تغییر نمی‌دهد و کنترل و مسئولیت داده‌های VPN کاملاً با خود کاربران است.

### 1.2 جمع‌آوری داده‌ها { #collection }

این برنامه به یک سرور خصوصی از طرف شما نیاز دارد و ما هیچ سروری فراهم نمی‌کنیم؛ پس نمی‌توانیم هیچ اطلاعاتی از شما جمع کنیم. اطلاعات خطا در برنامهٔ کلاینت هیدیفای از طریق Sentry و بدون هیچ اطلاعات حساسی فرستاده می‌شود.

<div class="hi-pp-note" markdown="1">

**چه اطلاعاتی ممکن است به سرور خصوصی شما (که خودتان یا دیگران راه انداخته‌اید) فرستاده شود؟**

برای افزودن لینک سرور به کلاینت، به یک لینک اشتراک نیاز دارید. با لینک اشتراک، سرور شما به این‌ها دسترسی دارد:

- آدرس IP شما (مثل هر درخواست HTTP دیگری؛ پس مراقب باشید به سرورهای ناشناس اعتماد نکنید)
- نسخهٔ هیدیفای شما

برای بهترین تجربه، ممکن است داده‌های ناشناس و محدودی روی سرور شما یا هر سرور دیگری جمع شود، آن هم فقط بعد از اجازهٔ صریح شما. این داده‌ها می‌توانند این‌ها باشند:

- اطلاعات آدرس IP کلاینت
- نسخهٔ سیستم‌عامل
- نسخهٔ برنامه
- وضعیت اتصال (پینگ TCP)

</div>
