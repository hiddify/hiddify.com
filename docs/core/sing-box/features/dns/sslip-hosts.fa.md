# نام‌های sslip.io در سرور hosts

[همهٔ قابلیت‌های هیدیفای](../../index.md)

نامی زیر `sslip.io` نشانی IP خودش را در خود دارد، مثل `1-2-3-4.sslip.io` برای `1.2.3.4`. سرور
DNS از نوع `hosts` در هیدیفای (`"type": "hosts"` در فهرست `dns.servers`) نشانی را از چنین نامی
می‌خواند و بدون پرسیدن از هیچ سرور DNS با آن پاسخ می‌دهد. فیلد تازه‌ای ندارد: هر سرور `hosts`
این کار را می‌کند.

## چرا از آن استفاده کنیم

- سرور دامنه ندارد اما کلاینت به دامنه نیاز دارد، مثلاً برای نام سرور TLS یا گواهی‌ای که برای یک
  نام `sslip.io` صادر شده است.
- در شبکهٔ فیلترشده، پرسش DNS برای این نام ممکن است ناموفق شود یا پاسخ نادرست بگیرد. خواندن
  نشانی از خود نام به هیچ پرسشی نیاز ندارد.

## چطور از فیلترینگ عبور می‌کند

برای این نام‌ها هیچ پرسش DNS از دستگاه بیرون نمی‌رود، پس مسدودسازی یا مسموم کردن DNS روی آن‌ها
اثری ندارد. خود اتصال همچنان به نشانی IP درون نام می‌رود و فیلتر می‌تواند آن را مسدود کند.

## چطور کار می‌کند

- سرور `hosts` اول در `predefined` و بعد در فایل‌های hosts خود می‌گردد. فقط وقتی هیچ‌کدام نام را
  نداشته باشند، نشانی را از خود نام می‌خواند.
- نشانی IPv4 با نقطه یا خط تیره نوشته می‌شود: `1.2.3.4.sslip.io` و `1-2-3-4.sslip.io` هر دو یعنی
  `1.2.3.4`. پیشوند پیش از نشانی مجاز است: `www.1.2.3.4.sslip.io` و `app-1-2-3-4.sslip.io` هم
  یعنی `1.2.3.4`.
- نشانی IPv6 با خط تیره به جای دونقطه نوشته می‌شود: `2a01-4f8-c17-b8f--2.sslip.io` یعنی
  `2a01:4f8:c17:b8f::2` و `--1.sslip.io` یعنی `::1`.
- TTL پاسخ ۱۰ دقیقه است. پرسش A فقط نشانی IPv4 و پرسش AAAA فقط نشانی IPv6 می‌گیرد؛ پرسش دیگر
  پاسخ خالی می‌گیرد.
- نامی که نشانی معتبر ندارد، مثل `foo.sslip.io`، پاسخ «چنین نامی وجود ندارد» می‌گیرد، مثل هر نام
  دیگری که سرور `hosts` نمی‌شناسد.

## پیکربندی

سرور `hosts` فقط به نام‌هایی که می‌شناسد پاسخ می‌دهد، پس با یک قاعدهٔ DNS فقط نام‌های `sslip.io`
را به آن بفرستید:

```json
{
  "dns": {
    "servers": [
      { "type": "hosts", "tag": "hosts" },
      { "type": "https", "tag": "remote", "server": "1.1.1.1" }
    ],
    "rules": [
      { "domain_suffix": ["sslip.io"], "server": "hosts" }
    ],
    "final": "remote"
  }
}
```

فیلدهای سرور `hosts` (`path` و `predefined`) مثل sing-box اصلی کار می‌کنند.
