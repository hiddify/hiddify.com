# ترنسپورت raw

[همهٔ قابلیت‌های هیدیفای](../../index.md)

`raw` یک ترنسپورت V2Ray است که چیزی اضافه نمی‌کند: پروتکل مستقیم روی TCP اجرا می‌شود، یا اگر بلوک
`tls` فعال باشد روی TLS. معادل نداشتن بلوک `transport` است و با شبکهٔ `raw` (پیش‌تر `tcp`) در Xray
یکی است. آن را با `"transport": {"type": "raw"}` روی ورودی یا خروجی VLESS، VMess یا Trojan تنظیم
کنید.

## چرا از آن استفاده کنیم

کانفیگ‌هایی که از Xray تبدیل شده‌اند، یا ابزارهایی که همیشه ترنسپورت را پر می‌کنند، بدون تغییر بارگذاری
می‌شوند. نودی که شبکهٔ Xray آن `raw` یا `tcp` است را می‌توان با `"type": "raw"` نوشت. در کانفیگی که
خودتان می‌نویسید به آن نیازی ندارید.

## چطور از فیلترینگ عبور می‌کند

عبور نمی‌کند. هیچ قاب‌بندی یا پوششی اضافه نمی‌کند؛ فیلتر خود پروتکل و لایهٔ TLS یا REALITY آن را
می‌بیند.

## چطور کار می‌کند

- کلاینت: با TCP به سرور وصل می‌شود، اگر TLS فعال باشد دست‌دهی TLS را انجام می‌دهد و اتصال را به
  پروتکل می‌دهد.
- سرور: اتصال‌های TCP را می‌پذیرد، اگر TLS فعال باشد دست‌دهی TLS را انجام می‌دهد و هر اتصال را به
  پروتکل می‌دهد. روی UDP گوش نمی‌دهد.

## پیکربندی

```json
{
  "outbounds": [
    {
      "type": "vless",
      "server": "example.com",
      "server_port": 443,
      "uuid": "bf000d23-0752-40b4-affe-68f7707a9661",
      "tls": { "enabled": true, "server_name": "example.com" },
      "transport": { "type": "raw" }
    }
  ]
}
```

| فیلد | نوع | پیش‌فرض | معنا |
|---|---|---|---|
| `type` | string | — | `raw`. این ترنسپورت فیلد دیگری ندارد. |
