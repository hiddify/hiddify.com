# آموزش استفاده از HiddifyCli (منتقل شد)

!!! warning "این آموزش منتقل شده است: HiddifyCli حالا هستهٔ هیدیفای است"
    **HiddifyCli** حالا **هستهٔ هیدیفای** (`hiddify-core`) نام دارد. آموزش آن به صفحه‌های هستهٔ هیدیفای منتقل شده و همان‌جا به‌روز نگه داشته می‌شود. این صفحه فقط برای این نگه داشته شده که لینک‌های قدیمی خراب نشوند.

[:material-console: راهنمای دستورها](../core/cli.md){ .md-button }

## مطالب این صفحه حالا کجاست

| می‌خواهید | ببینید |
|---|---|

دستورها همان قبلی‌اند و فقط نام برنامه عوض شده: `HiddifyCli run -c <link>` حالا `hiddify-core run -c <link>` است. در ویندوز نام فایل هنوز `HiddifyCli.exe` است.
