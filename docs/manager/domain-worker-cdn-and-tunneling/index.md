# Domain, Worker, CDN and tunneling

These guides help you connect domains to your HiddifyManager server: which domain type to choose, how to put your server behind a CDN such as Cloudflare, how to use Cloudflare Workers, how to find clean Cloudflare IPs, and how to keep subscription links reachable when other domains are blocked.

If you are new, start with [Domain types and how to register them](/manager/domain-worker-cdn-and-tunneling/Domain-types-and-how-to-register-them/) and [What is CDN and how does it help us?](/manager/domain-worker-cdn-and-tunneling/What-is-CDN-and-how-does-it-help-us%3F/).
