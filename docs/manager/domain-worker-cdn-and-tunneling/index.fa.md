# دامنه، ورکر، CDN و تانل

این آموزش‌ها به شما کمک می‌کنند دامنه‌ها را به سرور هیدیفای‌منیجر وصل کنید: کدام نوع دامنه را انتخاب کنید، چطور سرور را پشت یک CDN مثل Cloudflare قرار دهید، چطور از ورکرهای Cloudflare استفاده کنید، چطور آی‌پی تمیز Cloudflare پیدا کنید و چطور لینک اشتراک را حتی وقتی دامنه‌های دیگر مسدود شده‌اند در دسترس نگه دارید.

اگر تازه شروع کرده‌اید، از [انواع دامنه و آموزش ثبت آن‌ها](/fa/manager/domain-worker-cdn-and-tunneling/Domain-types-and-how-to-register-them/) و [CDN چیست و چه کمکی به ما می‌کند؟](/fa/manager/domain-worker-cdn-and-tunneling/What-is-CDN-and-how-does-it-help-us%3F/) شروع کنید.
