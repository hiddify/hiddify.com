# آموزش خاموش کردن آی‌پی ورژن ۶ در هیدیفای

این صفحه به شما نشان می‌دهد چطور IPv6 را روی سرور هیدیفای خاموش کنید. وقتی IPv6 مشکل ایجاد می‌کند، مثلاً وقتی گوگل به کاربران شما خطا نشان می‌دهد، به این کار نیاز دارید.

## IPv6 چیست؟

**IPv6** (آی‌پی ورژن ۶) نسل جدید آدرس‌های IP است که بعد از IPv4 معرفی شد. یک آدرس IPv6 طولی برابر ۱۲۸ بیت دارد و به شکل ۸ بخش ۴ کاراکتری **هگزادسیمال** (ارقام `0` تا `9` و حروف `a` تا `f`) نوشته می‌شود که با `:` از هم جدا شده‌اند. برای مثال:

<div dir=ltr markdown=1>
  
`2001:0db8:85a3:0000:0000:8a2e:0370:7334`
</div>

چون تعداد آدرس‌های IPv6 بسیار زیاد است، مسدود کردن آن‌ها سخت‌تر از IPv4 است. با این حال گاهی لازم است IPv6 را خاموش کنید.

## چه زمانی باید IPv6 را خاموش کنید؟

- **نشانه:** کاربران شما در گوگل خطا می‌بینند (مثلاً **۴۰۳** یا «unusual traffic») یا بعضی سایت‌ها باز نمی‌شوند، در حالی که بقیه سایت‌ها کار می‌کنند.
- **علت محتمل:** آدرس IPv6 سرور توسط آن سایت مسدود یا مشکوک شناخته شده است، یا IPv6 در دیتاسنتر سرور شما درست کار نمی‌کند.
- **راه‌حل:** IPv6 را خاموش کنید تا سرور فقط از IPv4 استفاده کند. اول روش ۱ (پنل) را امتحان کنید. فقط اگر به پنل دسترسی ندارید از روش ۲ استفاده کنید.

## روش ۱: از طریق پنل

1. وارد پنل مدیریت هیدیفای شوید.
2. صفحه **تنظیمات** را باز کنید.
3. در کادر جستجو (**جستجو در همه تنظیمات…**) عبارت `IPv4` یا `ورژن 4` را بنویسید. گزینه **فقط آی‌پی ورژن 4** در بخش **تنظیمات عمومی** و جزو تنظیمات پیشرفته است.
4. گزینه **فقط آی‌پی ورژن 4** را روشن کنید.
5. روی **ذخیره** بزنید.
6. وقتی پنل درخواست کرد، روی **اعمال تغییرات** بزنید تا تغییر اعمال شود.

وقتی این گزینه روشن باشد، هیدیفای IPv6 را روی کارت‌های شبکه سرور خاموش می‌کند و دیگر آدرس‌های IPv6 را در کانفیگ‌های کاربران قرار نمی‌دهد.

## روش ۲: از طریق SSH

فقط وقتی از این روش استفاده کنید که بخواهید IPv6 را برای کل سیستم‌عامل خاموش کنید.

1. [با SSH به سرور خود وصل شوید](/fa/manager/installation-and-setup/How-to-connect-to-server-via-SSH/). اگر منوی هیدیفای باز شد، با `Ctrl+C` از آن خارج شوید.
2. فایل تنظیمات سیستم را با ویرایشگر متنی **nano** باز کنید:

    ```bash
    sudo nano /etc/sysctl.conf
    ```

3. به انتهای فایل بروید و این سه خط را اضافه کنید:

    ```ini
    net.ipv6.conf.all.disable_ipv6=1
    net.ipv6.conf.default.disable_ipv6=1
    net.ipv6.conf.lo.disable_ipv6=1
    ```

4. با `Ctrl+S` فایل را ذخیره کنید و با `Ctrl+X` خارج شوید.
5. تنظیمات جدید را بارگذاری کنید:

    ```bash
    sudo sysctl -p
    ```

    این دستور همان سه خطی را که اضافه کردید نمایش می‌دهد. اگر خطایی دیدید، فایل را دوباره باز کنید و غلط تایپی را اصلاح کنید.

حالا IPv6 خاموش است و سرور فقط با IPv4 کار می‌کند. هیدیفای هم این را تشخیص می‌دهد و سرور را فقط-IPv4 در نظر می‌گیرد.

اگر بعداً خواستید IPv6 را دوباره روشن کنید، آن سه خط را پاک کنید، دوباره `sudo sysctl -p` را اجرا کنید و سرور را ری‌استارت کنید.
