# آموزش انتقال فایل بین سرور و کامپیوتر

در این صفحه یاد می‌گیرید که فایل‌ها را از سرور به کامپیوتر خود و برعکس منتقل کنید؛ مثلاً برای نگه داشتن یک نسخه از بکاپ هیدیفای یا آپلود یک فایل روی سرور.

!!! tip "فقط بکاپ پنل را لازم دارید؟"
    برای این کار به هیچ دستوری نیاز ندارید. در پنل مدیریت هیدیفای صفحه **پشتیبان‌گیری و بازیابی** را باز کنید و روی **دانلود پشتیبان** بزنید. [آموزش بکاپ‌گیری و بازیابی پنل](/fa/manager/configuration-and-advanced-settings/How-to-backup-and-restore-panel-on-Hiddify/) را ببینید.

## پیش از شروع

- آدرس IP سرور و نام کاربری SSH (معمولاً `root`) را می‌دانید و می‌توانید [با SSH به سرور وصل شوید](/fa/manager/installation-and-setup/How-to-connect-to-server-via-SSH/).
- روی کامپیوتر خود یک ترمینال باز کنید:
    - ویندوز: **PowerShell**
    - مک: **Terminal**
    - لینوکس: **Terminal**

در این صفحه از **scp** استفاده می‌شود؛ دستوری که فایل‌ها را از طریق SSH کپی می‌کند. این دستور در ویندوز ۱۰ و ۱۱، مک و لینوکس از قبل وجود دارد.

!!! note "اگر ویندوز می‌گوید `scp` شناخته نشد"
    PowerShell را **با دسترسی مدیر** باز کنید (روی PowerShell راست‌کلیک کنید و **Run as administrator** را بزنید) و این دستور را اجرا کنید تا OpenSSH Client نصب شود:

    ```powershell
    Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0
    ```


    سپس PowerShell را ببندید و دوباره باز کنید.

## پیدا کردن فایل روی سرور

هیدیفای منیجر هر ۶ ساعت یک بار به‌طور خودکار از پنل بکاپ می‌گیرد و آن را در `/opt/hiddify-manager/data/backup/` ذخیره می‌کند. برای دیدن فهرست بکاپ‌ها، با SSH به سرور وصل شوید و این دستور را اجرا کنید:

<div dir="ltr" markdown="1">

```bash
ls /opt/hiddify-manager/data/backup/
```

</div>

فایل‌هایی می‌بینید که با تاریخ و ساعت نام‌گذاری شده‌اند، مثل `2026_10_20__06_00_03.json`:

<div align=center markdown=1>

<img src="https://github.com/hiddify/hiddify-config/assets/125398461/924b149e-6ec8-4b48-8fbb-ad99a234ee5e" alt="نمونه فهرست فایل‌های بکاپ روی سرور" />
</div>

فایلی را که می‌خواهید منتقل کنید انتخاب کنید و نام آن را یادداشت کنید.

## انتقال فایل از سرور به کامپیوتر

این دستور را **روی کامپیوتر خودتان** اجرا کنید، نه روی سرور. شکل کلی دستور:

<div dir="ltr" markdown="1">

```bash
scp <user>@<server-ip>:<path/on/server> "<folder on your computer>"
```

</div>

مثال: نام کاربری شما `root`، آی‌پی سرور `1.1.1.1` است و می‌خواهید یک بکاپ را در پوشه `C:\Backup` کپی کنید:

<div dir="ltr" markdown="1">

```powershell
scp root@1.1.1.1:/opt/hiddify-manager/data/backup/2026_10_20__06_00_03.json "C:\Backup"
```

</div>

وقتی خواسته شد، رمز عبور سرور (یا عبارت عبور کلید) را وارد کنید. **اگر درست انجام شده باشد**، فایل در پوشه `C:\Backup` دیده می‌شود.

## انتقال فایل از کامپیوتر به سرور

این دستور را هم **روی کامپیوتر خودتان** اجرا کنید. مثال: فایل `C:\File\text.txt` باید به پوشه `/root/` روی سرور منتقل شود:

<div dir="ltr" markdown="1">

```powershell
scp "C:\File\text.txt" root@1.1.1.1:/root/
```

</div>

برای بررسی، با SSH به سرور وصل شوید و این دستور را اجرا کنید:

<div dir="ltr" markdown="1">

```bash
ls /root/
```

</div>

**اگر درست انجام شده باشد**، `text.txt` در فهرست دیده می‌شود.

## اگر کار نکرد

- **`No such file or directory`**: مسیر اشتباه است. آن را با `ls` روی سرور بررسی کنید و یادتان باشد که در لینوکس حروف بزرگ و کوچک فرق دارند (`hiddify-manager` درست است، نه `Hiddify-Manager`).
- **`Permission denied`**: نام کاربری، رمز عبور یا کلید اشتباه است، یا کاربر اجازه خواندن یا نوشتن در آن پوشه را ندارد. از `root` یا پوشه‌ای که مال کاربر شماست استفاده کنید.
- **`Connection timed out`**: آی‌پی سرور یا پورت SSH اشتباه است. اگر پورت SSH را تغییر داده‌اید، `-P` و شماره پورت را اضافه کنید (در scp حرف P بزرگ است)؛ مثلاً `scp -P 2222 ...`.

## استفاده از پنل وب

در هیدیفای منیجر نسخه ۱۴، پنل مدیریت صفحه‌ای به نام **ترمینال SSH** دارد که یک مرورگر فایل داخلی هم دارد. در آنجا می‌توانید بدون برنامه جداگانه فایل‌ها را روی سرور آپلود یا از آن دانلود کنید. رمز عبور سرور خود را در سایت‌های شخص ثالث وارد نکنید.
