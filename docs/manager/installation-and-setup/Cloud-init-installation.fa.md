# نصب آسان از طریق دیتاسنتر (Cloud-init)

اگر ارائه‌دهنده‌ی سرور شما اجازه می‌دهد هنگام ساخت سرور یک اسکریپت راه‌اندازی وارد کنید، از این روش استفاده کنید. در این حالت هیدیفای‌منیجر هنگام روشن شدن سرور خودکار نصب می‌شود و فقط آخر کار یک بار به سرور وصل می‌شوید تا لینک ادمین را ببینید.

**Cloud-init** ابزاری استاندارد است که اولین باری که سرور جدید روشن می‌شود، یک اسکریپت راه‌اندازی را اجرا می‌کند. بیشتر ارائه‌دهنده‌ها (Hetzner، Vultr، OVH، DigitalOcean و ...) از آن پشتیبانی می‌کنند. اسم این بخش معمولاً **User data**، **Cloud-init** یا **Custom data** است.

## قبل از شروع

- سیستم‌عامل سرور را **Ubuntu 26.04** یا **24.04** انتخاب کنید. اگر هیچ‌کدام در دسترس نبود، Ubuntu 22.04 هم کار می‌کند. نسخه‌های دیگر پشتیبانی نمی‌شوند.
- سروری با پردازنده‌ی **amd64 (x86_64)** یا **arm64** انتخاب کنید.

## مراحل

### ساخت سرور

1. در پنل ارائه‌دهنده‌ی سرور، ساخت یک سرور جدید را شروع کنید.
2. بخش cloud-init یا user data را پیدا کنید.
3. کد زیر را کپی کنید و در آن بخش قرار دهید.

### ادامه

1. سرور را بسازید.
2. ۱۰ تا ۱۵ دقیقه صبر کنید تا نصب تمام شود.
3. [با SSH به سرور وصل شوید](/fa/manager/installation-and-setup/How-to-connect-to-server-via-SSH/)، یا کنسول وب داشبورد ارائه‌دهندهٔ سرور را باز کنید، و دستور `hiddify admin` را اجرا کنید. لینک‌های ادمین نمایش داده می‌شوند: این همان لینک ادمین همیشگی سرور است (دیگر لینک موقت یک‌ساعته‌ای ساخته نمی‌شود). یکی از آن‌ها را در مرورگر باز کنید و جای امنی نگه دارید.

اگر `hiddify admin` پیام داد که دستور پیدا نشد، نصب هنوز تمام نشده است: چند دقیقهٔ دیگر صبر کنید و دوباره امتحان کنید.
