# نصب آسان از طریق دیتاسنتر (Cloud-init)

اگر ارائه‌دهنده‌ی سرور شما اجازه می‌دهد هنگام ساخت سرور یک اسکریپت راه‌اندازی وارد کنید، از این روش استفاده کنید. در این حالت هیدیفای‌منیجر خودکار نصب می‌شود و لازم نیست با SSH به سرور وصل شوید.

**Cloud-init** ابزاری استاندارد است که اولین باری که سرور جدید روشن می‌شود، یک اسکریپت راه‌اندازی را اجرا می‌کند. بیشتر ارائه‌دهنده‌ها (Hetzner، Vultr، OVH، DigitalOcean و ...) از آن پشتیبانی می‌کنند. اسم این بخش معمولاً **User data**، **Cloud-init** یا **Custom data** است.

## قبل از شروع

- سیستم‌عامل سرور را **Ubuntu 22.04، 24.04 یا 26.04** انتخاب کنید. نسخه‌های دیگر پشتیبانی نمی‌شوند.
- سروری با پردازنده‌ی **amd64 (x86_64)** یا **arm64** انتخاب کنید.

## مراحل

### ساخت سرور

1. در پنل ارائه‌دهنده‌ی سرور، ساخت یک سرور جدید را شروع کنید.
2. بخش cloud-init یا user data را پیدا کنید.
3. کد زیر را کپی کنید و در آن بخش قرار دهید.

### ادامه

1. سرور را بسازید.
2. ۱۰ تا ۱۵ دقیقه صبر کنید تا نصب تمام شود.
3. آدرس `http://YOUR-SERVER-IP/` را در مرورگر باز کنید (به جای `YOUR-SERVER-IP` آی‌پی سرور خود را بنویسید). یک لینک موقت به پنل ادمین می‌بینید. این لینک **فقط یک ساعت** کار می‌کند، پس زود آن را باز کنید.

اگر بعد از ۱۵ دقیقه صفحه باز نشد، چند دقیقه‌ی دیگر صبر کنید و دوباره امتحان کنید. اگر یک ساعت گذشته است، از طریق SSH به سرور وصل شوید و با دستور `hiddify admin` لینک‌های ادمین را ببینید ([راهنمای نصب اصلی](/fa/manager/installation-and-setup/guide/) را ببینید).

بعد از آن، [تنظیم دامنه و نهایی کردن نصب](/fa/manager/installation-and-setup/Guide-for-setting-up-the-domain-and-finalizing-the-installation/) را دنبال کنید.
