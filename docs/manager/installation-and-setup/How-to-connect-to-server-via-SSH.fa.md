# آموزش اتصال به سرور از طریق SSH

**SSH** روشی امن برای باز کردن خط فرمان یک سرور از راه دور، از روی کامپیوتر خودتان است. برای نصب هیدیفای‌منیجر به آن نیاز دارید. همچنین وقتی از طریق وب به پنل دسترسی ندارید (مثلاً لینک ادمین را گم کرده‌اید)، تنها راه درست کردن پنل اتصال از طریق SSH است.

## چه چیزهایی لازم دارید

- **آی‌پی** سرور (چهار عدد که با نقطه جدا شده‌اند، مثلاً `1.1.1.1`).
- **نام کاربری** و **رمز عبور** (یا کلید SSH) که ارائه‌دهنده‌ی سرور به شما داده است. نام کاربری معمولاً `root` است.
- یک برنامه‌ی SSH روی کامپیوترتان. ویندوز ۱۰ و ۱۱، مک و لینوکس از قبل آن را دارند.

<details markdown="1"><summary>فقط ویندوز: نصب SSH اگر وجود ندارد</summary>

ویندوز ۱۰ و ۱۱ معمولاً SSH را از قبل دارند. اگر دستور `ssh` پیدا نشد:

1. روی **PowerShell** راست‌کلیک کنید و **Run as Administrator** را بزنید.

    ![باز کردن PowerShell با دسترسی ادمین](https://user-images.githubusercontent.com/114227601/222904592-cd26b3bf-a014-4253-9488-ee9717f006fe.png)

2. این دستور را اجرا کنید:

    ```powershell
    Add-WindowsCapability -Online -Name OpenSSH.Client
    ```

3. باید نتیجه‌ای شبیه این ببینید:

حالا SSH نصب شده است.

## اتصال به سرور

1. یک ترمینال روی کامپیوترتان باز کنید:
    - ویندوز: **PowerShell**
    - مک: **Terminal**
    - لینوکس: **Terminal**
2. این دستور را بنویسید، به جای `<IP_Address>` آی‌پی سرور را قرار دهید و Enter بزنید:

    ```bash
    ssh root@<IP_Address>
    ```

    مثلاً اگر آی‌پی سرور شما `1.1.1.1` است:

    ```bash
    ssh root@1.1.1.1
    ```

3. بار اول، SSH می‌پرسد آیا به این سرور اعتماد دارید (`Are you sure you want to continue connecting`). کلمه‌ی `yes` را بنویسید و Enter بزنید.
4. رمز عبور را وارد کنید و Enter بزنید. هنگام تایپ، رمز روی صفحه نمایش داده نمی‌شود؛ این طبیعی است.

وقتی وصل شدید، خط فرمان به چیزی شبیه `root@your-server:~#` تغییر می‌کند. حالا می‌توانید روی سرور دستور اجرا کنید.

اگر پیام `Connection timed out` یا `Connection refused` دیدید، آی‌پی و پورت را بررسی کنید و مطمئن شوید سرور روشن است.

## اگر پورت SSH را تغییر داده‌اید

SSH به طور پیش‌فرض از پورت 22 استفاده می‌کند. اگر آن را تغییر داده‌اید، `-p` و شماره‌ی پورت را اضافه کنید:

```bash
ssh root@<IP_Address> -p <port_number>
```

مثلاً اگر آی‌پی شما `1.1.1.1` و پورت `2222` است:

```bash
ssh root@1.1.1.1 -p 2222
```

## دستورهای کاربردی بعد از اتصال

اگر هیدیفای‌منیجر از قبل نصب شده است، این دستورها برای مدیریت آن به کار می‌آیند:

- `hiddify`: منوی مدیریت را باز می‌کند.
- `hiddify admin`: لینک‌های پنل ادمین را نشان می‌دهد.
- `hiddify status`: وضعیت سرویس‌ها را نشان می‌دهد.
- `hiddify restart`: سرویس‌ها را ری‌استارت می‌کند.

مثلاً برای دیدن لینک‌های ادمین:

```bash
hiddify admin
```

برای نصب هیدیفای‌منیجر، [راهنمای نصب اصلی](/fa/manager/installation-and-setup/guide/) را دنبال کنید.
