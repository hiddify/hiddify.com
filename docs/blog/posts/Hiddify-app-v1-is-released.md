# Hiddify app 1.0: the name is Hiddify

<!-- made by .cache/blog/history_gen.py -->

!!! abstract "In 30 seconds"
    The **Hiddify app 1.0** came out on 18 March 2024, with a Nowruz theme. Hiddify Next is now simply
    **Hiddify**. It has **WARP built in**, **smart fragment**, **quick settings**, and a **VPN service** on
    Windows and Linux, so you don't need to run it as administrator every time.

<!-- more -->

## What was new

- **WARP built in.**
- **Smart fragment** (TLS Tricks, more mature).
- **Quick settings** on the home page.
- **VPN service on Windows and Linux:** VPN mode without asking for administrator rights each time.
- **Failover:** if a config fails, the app moves to another one.
- **Connection info** on the home page: the active server, speed, IP and ping under the connect button.
- **WireGuard noise**, and importing Clash and sing-box configs.
- **New icons and navigation**, and haptic feedback.
