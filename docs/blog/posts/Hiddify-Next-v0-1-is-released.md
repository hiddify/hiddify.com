# Hiddify Next 0.1: the first version of the Hiddify app

<!-- made by .cache/blog/history_gen.py -->

!!! abstract "In 30 seconds"
    On 11 September 2023 we released **Hiddify Next 0.1**, the first version of the app that is now the **Hiddify
    app**. One simple app for **Android, Windows, Linux and macOS**, built on the sing-box core, that opens V2Ray,
    Clash and sing-box subscription links.

<!-- more -->

## What was new

- **One app on four systems:** Android, Windows (installer and portable), Linux (AppImage) and macOS.
- **Opens the common links:** V2Ray subscription links, Clash and Clash Meta links, and sing-box configs.
- **Profiles** with their traffic and expiry date shown from the subscription.
- **Persian language** and font from the start.
- **Deep links** (`hiddify://`), an Android quick-settings tile, and VPN (TUN) mode.
- **Per-app proxy on Android** (0.5): choose which apps use the proxy.
- **Region choice** at the first start (0.5).
