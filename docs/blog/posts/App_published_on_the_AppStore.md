# Hiddify is now approved and available on the AppStore! 🎆

!!! abstract "In 30 seconds"
    On 31 October 2024 the Hiddify app came out on Apple's **App Store**. With it, Hiddify works on every big platform: iOS,
    Android, Windows, Linux and Mac. It is free, has no ads and is open source (GPL v3).

</div>

## What this means for you

- **iPhone and iPad users** can install Hiddify from the App Store, like any other app.
- **One app everywhere**: the same simple app on iOS, Android, Windows, Linux and Mac.
- **Free, no ads, open source**: the code is on GitHub under GPL v3, so anyone can check it.

We made the app so simple that even grandparents can use it comfortably. 💪

Our path is clear: free internet is everyone's right. With your support we can go further on this road. 😍
