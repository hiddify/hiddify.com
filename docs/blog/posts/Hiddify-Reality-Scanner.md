# Hiddify Reality Scanner: find the best SNI for Reality

<!-- made by .cache/blog/history_gen.py -->

!!! abstract "In 30 seconds"
    When new limits on Reality appeared, we released the **Hiddify Reality Scanner** on 22 November 2023. It
    checks a list of sites on **your own network** and finds the SNIs that work best for a Reality domain. Seven
    versions came out in its first week.

<!-- more -->

## What was new

- **Finds working SNIs** for Reality on the network you are on.
- **Server and client parts.**
- **A limit option**, and a README in Persian.
- **13 releases in one week** (1.0 to 1.8).
- **251 stars** on GitHub.
