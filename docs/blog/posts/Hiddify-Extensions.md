# Hiddify extensions: anyone can add a feature

<!-- made by .cache/blog/history_gen.py -->

!!! abstract "In 30 seconds"
    With **hiddify-core 3.0** on 28 September 2024, the Hiddify app got **extensions**: anyone can add a feature
    and its own screen to the app. The first one was an **IP scanner**, and a template makes a new extension easy
    to start.

<!-- more -->

## What was new

- **Extensions** with their own screens, on every platform.
- **IP scanner extension**, based on the warp-plus scanner.
- **A template** for developers ("Use this template" on GitHub), and a demo with every UI element.
- **Test in a browser** while you build it.

## Today

Today these tools live inside the Hiddify app and Hiddify Manager. Start with the app, or run your own server.
