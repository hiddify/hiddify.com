# Hiddify app 2: config editor and two cores

<!-- made by .cache/blog/history_gen.py -->

!!! abstract "In 30 seconds"
    The **Hiddify app 2.0** came out on 30 July 2024. You can now **edit a config** inside the app and set a **URL
    test** for each profile. In the 2.x versions the app also learned to use the **Xray core** next to sing-box,
    and it reached **2.5.7** in October 2024.

<!-- more -->

## What was new

- **Config editor** (JSON), richer in 2.0.4, and a link checker.
- **Custom URL test** for each profile.
- **Use the Xray core** next to sing-box (2.2).
- **gVisor** as the default VPN stack, and a new default WARP mode (2.2).
- **Window close button:** choose to exit or minimize (2.5.7), and an exit dialog (2.1.4).
- **Regions:** Turkey (2.1.1) and Brazil (2.3); French language (2.1.4).
- **Edge-to-edge** screens on Android (2.5).

## Today

The Hiddify app is at version 5 now, with free profiles, Chain and connection sharing. Download the latest version.
