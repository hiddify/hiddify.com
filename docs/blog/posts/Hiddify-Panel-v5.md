# Hiddify panel 5: domain types and usage in the link

<!-- made by .cache/blog/history_gen.py -->

!!! abstract "In 30 seconds"
    **Hiddify panel 5** came out on 26 April 2023, one week after panel 4. It made **adding domains** easier with
    **domain types**, put each user's **usage in the subscription link**, and changed the colours.

<!-- more -->

## What was new

- **Domain types** when you add a domain, and an easier "add domain" form.
- **Domain suggestions** in about 10 seconds.
- **Usage in the subscription link** (5.0.1), so apps show how much is left.
- **New colours** for the panel.

## Today

Hiddify Manager is at version 14 now. Install the latest version, or update yours from the panel (take a [backup](/manager/configuration-and-advanced-settings/How-to-backup-and-restore-panel-on-Hiddify/) first).
